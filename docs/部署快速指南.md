## 二、部署到 Vercel（线上看效果）

### 1. 准备代码仓库

确保项目在 **GitHub / GitLab / Bitbucket** 上（若还没有，在项目目录执行 `git init` 并 push 到远程）。

### 2. 在 Vercel 创建项目

1. 打开 [vercel.com](https://vercel.com)，登录
2. **Add New** → **Project**，选择你的仓库
3. 框架选 **Next.js**（一般会自动识别）
4. **Build Command**：`pnpm run build`（或保持默认）
5. **Install Command**：`pnpm install`
6. 先不填环境变量，直接点 **Deploy**

### 3. 不接数据库时

- 不配置 `DATABASE_URL` 即可
- 部署成功后用 Vercel 给的 URL 访问，行为与本地“内存模式”一致

### 4. 接数据库（可选，数据持久化）

**方式 A：Vercel Postgres**

1. 在 Vercel 项目里：**Storage** → **Create Database** → **Postgres**
2. 创建后在 **Environment Variables** 中会看到 `POSTGRES_URL`
3. 在项目 **Settings → Environment Variables** 新增：
   - Name: `DATABASE_URL`
   - Value: 与 Postgres 的 **Connection string** 相同（若 Vercel 只给 `POSTGRES_URL`，则 Value 填 `POSTGRES_URL` 的值）
4. 在 `prisma/schema.prisma` 里把 `url = env("DATABASE_URL")` 改为 `url = env("POSTGRES_URL")`，或保持 `DATABASE_URL` 并在 Vercel 里把连接串填到 `DATABASE_URL`

**方式 B：Neon（免费额度）**

1. 在 [neon.tech](https://neon.tech) 创建项目，复制连接串（带 `?sslmode=require`）
2. Vercel 项目 **Settings → Environment Variables** 添加：
   - `DATABASE_URL` = 粘贴连接串

**首次用数据库时**

- 本地执行一次（把 `DATABASE_URL` 换成生产库连接串）：
  ```bash
  pnpm db:push
  pnpm db:seed   # 可选：写入种子数据
  ```
- 或使用迁移：先本地 `pnpm exec prisma migrate dev --name init`，把 `prisma/migrations` 提交后，在 Vercel 的 Build Command 里加上：`prisma migrate deploy &&`（在 `next build` 前）

### 5. 重新部署

改环境变量或代码后，在 Vercel 项目里点 **Redeploy** 即可。

## 三、常用命令速查

| 命令 | 说明 |
|------|------|
| `pnpm dev` | 本地开发，默认 http://localhost:3000 |
| `pnpm build` | 生产构建（含 prisma generate） |
| `pnpm start` | 本地以生产模式运行（需先 `pnpm build`） |
| `pnpm db:generate` | 仅生成 Prisma Client，无需数据库 |
| `pnpm db:push` | 把 schema 推到数据库（不生成迁移文件） |
| `pnpm db:seed` | 写入种子数据（需已配置 DATABASE_URL） |

---

**总结**：想先看效果 → 本地 `pnpm dev` 或 Vercel 部署（不配库即可）；要数据持久化 → 配好 `DATABASE_URL` 并执行一次 `db:push`（及可选 `db:seed`）。
